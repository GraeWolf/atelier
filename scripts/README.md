# Helper scripts

Project automation scripts (build personal repo, invoke ISO build, common checks).

| Script | Purpose |
|--------|---------|
| `sync-atelier-config-files.sh` | Copy `configs/` → `packages/atelier-config/files/` |

More scripts land in Steps 3–4 (repo/ISO builds). Prefer small, readable shell with clear usage comments.

Do not place secrets or private keys here.
